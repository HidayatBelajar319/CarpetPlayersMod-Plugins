Sekarang Bikinkan aku system Real-Sync In-Game.

Fitur ini memungkinkan Player memodifikasi File-File yang dipake oleh Minecraft akan ke Sync biarpun saat masih di In-Game menggunakan command Client-Side dan Server-Side yaitu /reload.
command ini akan memodifikasi system minecraft untuk memakai File yang udah diedit dan memungkinkan fitur itu langsung ke Sync ke Minecraft biarpun saat masih di In-Game.
Nah command /reload ini bawaan minecraft cuman kita nambahin fitur lebih bagus yaitu Real-Sync In-Game, Nah jadi jika belum bisa generate karena tidak tau atau mungkin masih belum paham ini aku jelasin dalam bentuk Structure setauku:
Player lagi In-Game --> Player Edit File Konfigurasi Dari salah satu mod yang generate file ini --> Minecraft belum sesuain Fitur baru yang ada di file tersebut --> Player jalanin command /reload bawaan minecraft --> CarpetPlayers Membuat Real-Time Sync In-Game lalu inject ke Minecraft system
--> System konfigurasi masuk --> Minecraft terubah system filenya lalu Fitur tersebut masuk biarpun masih In-Game.

Sama seperti saat kita buat atau edit file/folder didalam "datapack" folder di dalam World Save nanti sisa gunain command /reload(atau mungkin /reloads?) nanti datapack nya masuk In-Game.
